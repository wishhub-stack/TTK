# Квест

Мокап сайта для квеста: 3 этапа, на каждом — ввод найденного кода, после
которого открываются координаты следующей точки, фото ориентира, а на 2 и 3
этапе — ещё и подарочный код (Золотое Яблоко, Cartier).

## Как выложить на GitHub Pages

1. Создай новый репозиторий на GitHub (например `quest`).
2. Залей туда файлы `index.html`, `style.css`, `script.js` и папку `images`
   (через веб-интерфейс — "Add file → Upload files" — или через git).
3. Зайди в репозитории в **Settings → Pages**.
4. В разделе "Build and deployment" выбери **Deploy from a branch**, ветку
   `main` и папку `/ (root)`. Сохрани.
5. Через минуту-две сайт появится по адресу вида
   `https://твой-логин.github.io/quest/`.

## Как заполнить квест реальным содержанием

Всё редактируется в файле **script.js**, в самом начале — блок `STAGES`.
Для каждого этапа там есть:

- `code` — секретный код, который девушка должна найти на месте
- `heading` / `text` — текст, который появится после верного кода
- `coords` — координаты следующей точки (просто текст, можно в любом
  формате — адрес, "55.7522, 37.6156" и т.д.)
- `mapsUrl` — ссылка на Google Maps/Яндекс Карты с этой точкой (необязательно)
- `photo` — путь к фото ориентира, например `images/stage1.jpg`
- `gift` — подарочный код (`brand` и `code`); на первом этапе оставь `null`

Фото просто положи в папку `images/` с такими же именами, как указано в
`photo` — они подставятся автоматически. Если файла нет, вместо фото будет
пустая рамка с подписью — это нормально для мокапа.

## Проверка / сброс

Прогресс сохраняется в браузере (localStorage), поэтому страницу можно
закрывать и открывать заново — этап не потеряется.

Чтобы сбросить прогресс во время тестирования, открой сайт со `?reset` в
конце ссылки, например:
`https://твой-логин.github.io/quest/?reset`
